# Album Tracker

## A music album tracking application built with React and Vite. Album Tracker allows users to discover music albums, view album details, listen to track previews, manage a personal collection, and receive AI-powered album recommendations.

# Features

# Discover Albums:

    * Search for albums and artists using the iTunes Search API.
    * View album artwork, details, and track listings.
    * Listen to 30-second track previews.

# Album Details:

    * View album information and track lists.
    * Play available track previews.
    * Find albums on Spotify, YouTube, and Apple Music.

# Mini Player:

    * Play and pause music previews.
    * Skip to the previous or next track.
    * Control playback using the seek bar.
    * Continue playback while browsing the application.

# My Collection:

    * Save albums to a personal collection.
    * Organize albums using listening statuses:
        - Want to listen
        - Listening
        - Listened
    * Rate albums using a 1–5 star rating system.
    * Add personal notes to saved albums.
    * Filter and sort the collection.

# Full Album Playback with Deezer

    * Search Deezer for matching albums.
    * Display the Deezer full-album playback option when a matching album is available.
    * Use the Deezer embedded player to listen to supported albums.

# AI-Powered Recommendations

    * Receive album recommendations based on the user's saved albums and ratings.
    * Generate recommendations using Google's Gemini API.
